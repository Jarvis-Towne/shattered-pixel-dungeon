# 犟牛地牢 v1.1.0：成长进化版

> 工龄会涨，黑锅有上限。该躲的攻击，还是得躲。

## 本版新增

### 武器、护甲与本命神器共同成长

普通有效命中和实际承受敌方直接伤害积累历练；牛铃实际伤害敌人、英雄护甲能力完成有效使用也提供历练。达到 **12／40／90 历练** 且英雄等级达到 **3／8／14** 时，依次进化为「熟练工牛」「犟角行家」「老牌犟牛」。两项条件需同时满足，等待和空放不成长。

| 装备 | 成长路线 | 玩法变化 |
| --- | --- | --- |
| 武器 | 犟角 → 讲理角锤 → 抬杠扳手 → 老班长的犟角 | 基础伤害逐步提升，一阶起每第三次有效武器命中追加有限伤害；后期附短暂残废与易伤 |
| 围兜 | 拼斑围兜 → 值班围兜 → 不背锅围裙 → 老班长的围裙 | 受伤积攒有限黑锅，下一次普通攻击最多卸 2 层；高阶小护盾有 8 回合冷却，脱下清空黑锅 |
| 牛铃 | 不服铃 → 申诉小铃 → 调解牛铃 → 主持公道铃 | 移动后顶撞附短暂虚弱、两招交替配合、解锁短程防守声波 |

武器和围兜继续支持原有强化、附魔或刻印；成长不改变强化等级。围兜保持布甲防御，星牧战铠保留皇冠所升级护甲的属性并继承围兜机制。

### 牛铃新增交替配合与「据理力争」

二阶后，6 回合内交替使用实际命中敌人的顶撞与踏地，可以让顶撞额外造成 2 点伤害，或让踏地的基础护盾多 2 点。两招仍各耗 3 倔劲与 1 回合，配合完成后窗口消失，同招和空放没有额外奖励。

三阶「据理力争」消耗 4 倔劲，在 2 格范围内对可见且无墙阻挡的敌人造成少量物理伤害与短暂虚弱；首领与小头目的虚弱时间更短。它不伤友军、不停住敌人、不返还倔劲，也不参与配合。

牛铃新增只读的 **「成长手册」** 和 **「牛言牛语」** 菜单；查看不消耗资源或回合。手册、完整相册和专属物品的长说明支持滚动，物品操作按钮固定显示。

### 三项英雄护甲能力分别练习

「万蹄奔雷」「方寸牧场」「夜半开工」分别在 **3／7 次有效使用**后获得两级小幅强化，包括首个目标短暂虚弱、有限护盾、移除一次残废或延长少量时间。每项各自保存进度，不降低充能费用；对空地放技能不能刷熟练。

### 新增 18 个一次性彩蛋条目

探索、食物、怪物和技能熟练会留下新的牛言牛语。牛铃相册只显示已经发现的条目。绝大多数仅有对白与收集记录；两项各提供一次 2 点护盾、3 回合的小奖励，不形成可重复收益。已有草丛、镜子与 NPC 彩蛋继续保留。

完整效果和可折叠的触发说明见 [玩法指南](jiangniu-guide.md)。现有像素美术全部复用，原始桌宠与下载入口继续展示在 README。
