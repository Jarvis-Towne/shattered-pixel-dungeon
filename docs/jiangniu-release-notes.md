# 犟牛地牢 1.0.0 体验版

把桌面上那只皱眉的小牛，带进真正的像素地牢。

## 本版内容

- 开局直接选择第七职业「犟牛」，保留原版六职业。
- 以「倔劲」为核心的新战斗循环：普通攻击造成有效伤害或承受敌人直接伤害时积攒，摇响「不服铃」发动顶撞和踏地。
- 专属武器「犟角」、起始装备「拼斑围兜」、英雄护甲「星牧战铠」。
- 「温热牛乳」「口袋草饼」「裂纹牛铃」，以及六种新增状态。
- 两条转职：「撼地蛮牛」「守夜牧卫」；26项新天赋。
- 三种英雄护甲技能：「万蹄奔雷」「方寸牧场」「夜半开工」。
- 完整中文说明、NPC专属对白，以及留给你自己发现的小彩蛋。
- 参考用户提供的桌宠重绘像素素材：168个动作格、护甲层级、物品与技能图标、选人插画、胜利头像。

## 下载与安装

下载仓库 **[Jiangniu-v1.0.0.apk](../downloads/Jiangniu-v1.0.0.apk)**，在 Android 手机上打开并允许该下载来源安装应用。

应用名称为「犟牛地牢」，包名 `com.jarvistowne.jiangniu`。支持 Android 5.0 及以上，包含 ARM 32/64位和 x86 32/64位原生库，与原版分开安装和保存进度。建议正常游玩使用 ARM64 手机。

此版本使用固定的公开开发签名，便于后续体验版覆盖更新。它是侧载体验版本，不是应用商店发行签名版。当前上传文件已完成资源与中文检查、24项核心逻辑测试、APK编译与签名验证、Android 9 模拟器安装和开局/移动/技能/转职/存档恢复冒烟测试。此轮采用手动上传，不运行 GitHub Actions。

自动化验证不能替代所有真机和完整通关测试；平衡与长期游玩反馈将在后续版本继续调整。

## 玩法提示

开局已有3点倔劲，基础上限6点。点击快捷栏中的牛铃可瞄准敌人发动顶撞；要使用踏地，打开背包、点击「不服铃」，在道具菜单中选择「踏地」。倔劲不足时，先用普通攻击对敌人造成有效伤害来积攒；原地等待、技能伤害和零伤害命中不会恢复。

击败天狗后使用面具选择转职，击败矮人王后通过皇冠解锁一种专属护甲技能。草丛、安静的镜子和足够多次的坚持，也许会对这只小牛作出不一样的回应。
