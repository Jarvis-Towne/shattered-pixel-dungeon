# 犟牛地牢：玩法与开发说明

## 一、它是谁

「犟牛」来自用户提供的黑白小牛桌宠：粗眉毛、短角、圆肚子和不服气的表情。它不是原有英雄的重命名，而是追加在六职业之后的第七个可选职业。原有职业枚举编号保留，牛从第一次打开游戏就可选择。

所有新增可见文本均为中文；本分支首次启动默认简体中文。其他语言仍可选择，奶牛的原创内容统一回退到中文。

## 二、核心循环

普通攻击对敌人造成有效伤害，或实际承受敌人的直接伤害时积累「倔劲」，用来驱动牛铃技能。开局3点，基础上限6点，天赋可增加容量。等待、饥饿、中毒和友方攻击不会免费补充；技能伤害与零伤害命中也不会积攒。

| 内容 | 作用 |
| --- | --- |
| 不服铃 | 放在背包即可使用，不占饰品栏。提供顶撞与踏地，各消耗3点倔劲和1回合 |
| 顶撞 | 接近直线内可见敌人，冲锋越远伤害越高；附加残废。路径受墙、深渊、其它生物阻挡，逐格触发陷阱和地形 |
| 踏地 | 攻击相邻敌人并施加残废，同时获得短时护盾。部分天赋可解残废与缠绕 |
| 犟角 | 可升级、可附魔的专属短柄角锤。伤害受英雄等级、倔劲储备和天赋影响 |
| 拼斑围兜 | 可升级与刻印的起始布甲。倔劲充足时额外抵挡普通攻击伤害 |
| 温热牛乳 | 半份口粮的饱腹感，附带分回合恢复；不构成无限堆叠治疗 |

取消瞄准或选择无效目标不扣除倔劲。有效冲锋如果途中被陷阱、缠绕或新出现的敌人打断，已经付出的资源和回合仍然消耗。

点击快捷栏中的牛铃可瞄准敌人发动顶撞。踏地通过背包中的「不服铃」道具菜单使用；长按快捷栏属于原版的重新设置快捷道具操作。

牛铃不会被普通丢弃或投掷，避免误操作失去职业核心。更换武器后，犟牛仍能积攒倔劲与使用牛铃。

## 三、转职与英雄护甲

击败天狗、使用天狗面具后，沿原版流程二选一：

| 转职 | 玩法 |
| --- | --- |
| 撼地蛮牛 | 顶撞伤害提高25%，成功冲锋后强化3回合内的下一次有效命中；转职天赋可追加余震、追击伤害和护盾 |
| 守夜牧卫 | 成功使用牛铃后获得随等级成长的守牧护盾；转职天赋可保护附近友方，或触发有冷却时间的少量持续恢复 |

击败矮人王、使用皇冠，把当前护甲转为「星牧战铠」，保留其基础防御与强化，选择一种英雄技能：

| 英雄技能 | 行为 |
| --- | --- |
| 万蹄奔雷 | 向前发出贯穿生物、遇墙停止的蹄声冲击，沿线造成物理伤害与残废。英雄本体留在原处 |
| 方寸牧场 | 在施法位置建立固定守护区域，保护友方并减速敌人。墙阻断作用，换层或切换支线后失效 |
| 夜半开工 | 暂时提高移动速度和普通攻击伤害，带来照明与法杖充能，并补充少量倔劲 |

新增26项专属天赋：一阶4项、二阶5项、三阶共用2项、两种转职各3项、三种护甲技能各3项。四阶还使用原有的「英勇能量」。每项专属天赋均有实际机制引用，不占用原英雄的枚举编号。

## 四、状态与存档

| 状态 | 说明 |
| --- | --- |
| 倔劲 | 持久职业资源；显示当前量，保存到存档 |
| 守牧 | 有时间限制的护盾；重复施加取较高护盾与较长时长，不直接相加 |
| 余势 | 撼地蛮牛冲锋后，强化下一次有效命中 |
| 反刍 | 有限总量、逐回合恢复生命；药水恐惧挑战会阻止治疗 |
| 夜班精神 | 夜半开工带来的移动和战斗强化 |
| 方寸牧场 | 记录施法中心、楼层、支线、范围与剩余时长的区域效果 |

职业、转职、专属装备、天赋、技能、状态计数和彩蛋触发标记均使用原版 Bundle 持久化。保持原版6个同时存档槽；可选职业数量与存档槽数量分开管理，避免小屏幕存档列表溢出。

## 五、验证与发布方式

本版本由已经完成构建和验证的本地安装包直接上传到仓库的 `downloads/Jiangniu-v1.0.0.apk`，**本次不使用 GitHub Actions**，也没有在云端重新构建 APK。

之前已完成：像素图集及中文资源检查、24 项核心逻辑测试、Android Lint（0 错误）、APK 签名与四类原生架构检查；Android 9 模拟器安装后的选人、移动、顶撞/踏地相关操作、转职、护甲技能和存档恢复流程测试通过。上述测试不等于真机全流程通关或长期平衡验证。

直接下载：[`downloads/Jiangniu-v1.0.0.apk`](../downloads/Jiangniu-v1.0.0.apk)；完整性校验：[`downloads/SHA256SUMS.txt`](../downloads/SHA256SUMS.txt)。

本地回归测试可以执行：

```bash
python tools/check_cow_assets.py
./gradlew :core:test :android:assembleDebug :android:lintDebug
```

如需 Android 仪器化测试，可再运行 `:android:assembleDebugAndroidTest` 并在测试模拟器上执行 `tools/android_smoke.sh`。该脚本使用独立存档槽 99，不建议在日常游戏存档上运行。仓库中的下载 APK 为预先测试过的交付二进制文件，重新构建得到的文件不保证字节级哈希相同。

## 六、本地构建

需要 JDK 17、Android SDK Platform 36、Build Tools 36.0.0；Gradle 使用仓库自带 wrapper（9.5.0）。在根目录创建不入库的 `local.properties`，例如 `sdk.dir=/你的/Android/SDK`。

```bash
python -m pip install Pillow==11.3.0
python tools/check_cow_assets.py
bash gradlew :core:test :android:assembleDebug :android:assembleDebugAndroidTest :android:lintDebug
```

APK 默认输出到 `android/build/outputs/apk/debug/android-debug.apk`。Windows 可用 `gradlew.bat` 替代 `bash gradlew`。运行 Android 冒烟测试必须使用测试模拟器；脚本使用独立槽99，不应拿日常存档做测试。

包名为 `com.jarvistowne.jiangniu`，与原版共存。固定公开开发密钥的适用范围、升级行为与正式发行迁移说明见 `tools/signing/README.md`。
