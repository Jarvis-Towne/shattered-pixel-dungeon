# 犟牛地牢 v1.1.0：玩法与开发说明

## 一、它是谁

「犟牛」来自 Jarvis 创作的 Codex 桌宠「牛哞」：粗眉毛、短角、圆肚子和不服气的表情。它是追加在原有六职业之后的第七个可选职业；原有职业枚举编号保留，开局即可选择。

这一版通过历练与实际使用解锁进化。幽默体现在装备、动作、台词和收集里，战斗仍要求合理走位、分配资源、升级或更换装备。已有美术资源全部复用。首次启动默认简体中文，原创机制文本在其他语言下仍回退到中文。

## 二、倔劲与基础操作

普通攻击对敌人造成有效伤害，或实际承受敌人的直接伤害时积累「倔劲」。开局 3 点，基础上限 6 点，天赋可增加容量。等待、饥饿、中毒、友方攻击和零伤害命中不会免费补充；牛铃技能伤害本身也不补倔劲。

| 内容 | 作用 |
| --- | --- |
| 牛铃 | 放在背包即可使用，不占饰品栏。顶撞与踏地各消耗 3 倔劲、1 回合 |
| 顶撞 | 接近直线内可见敌人，造成 `4＋英雄等级＋实际移动格数×2` 的物理伤害，扣除敌人防御后至少 1；附加 3 回合残废 |
| 踏地 | 对相邻敌人造成 `3＋英雄等级÷2` 的物理伤害，扣除防御后至少 1；附加 2 回合残废，并给予 `2＋英雄等级÷5` 点、持续 4 回合的基础护盾 |
| 犟角 | 可升级、可附魔的专属角锤，伤害受英雄等级、倔劲储备与天赋影响 |
| 拼斑围兜 | 可升级、可刻印的起始布甲；倔劲至少 3 点时额外抵挡 1 点敌方普通攻击伤害 |
| 温热牛乳 | 有限食物补给，附带逐回合恢复；不构成无限堆叠治疗 |

表中除法按游戏整数运算向下取整，未计入转职和天赋修正。基础顶撞范围 3 格，天赋可增加。冲锋路径受到墙、深渊和其他生物阻挡，每格实际触发地形与陷阱。取消瞄准或选错目标不会付费；已经开始的冲锋若途中遭到缠绕、瘫痪、陷阱或新生物阻挡，已经消耗的资源和回合不退还。

点击快捷栏牛铃瞄准顶撞。踏地、成长手册、牛言牛语从背包中牛铃的道具菜单打开。长按快捷栏仍是原版更换快捷道具操作。牛铃不能普通丢弃或投掷，避免误操作失去职业核心；更换武器仍可积攒倔劲、使用牛铃。

## 三、共同历练与装备进化

历练是本局成长记录，不会被使用技能消耗；倔劲才是战斗资源。两者分开保存。

| 有效事件 | 历练 |
| --- | --- |
| 普通攻击对敌人造成有效伤害 | ＋1 |
| 实际承受敌方直接伤害 | ＋1 |
| 一次牛铃招式实际伤害敌人；顶撞需伤害主目标 | ＋2；命中多人仍只计一次 |
| 一次英雄护甲能力完成有效使用 | ＋3；每次施放最多一次 |

空放、无效目标、免疫后没有实际损失的命中不能练级。顶撞的历练与配合以主目标受伤为准，单独伤到旁边敌人的余震不计。历练有上限，不会无限提高阶段。以下历练与等级门槛必须同时满足：

| 阶段 | 历练 | 英雄等级 | 阶段名称 |
| --- | --- | --- | --- |
| 初始 | 0 | 1 | 初出牛棚 |
| 一阶 | 12 | 3 | 熟练工牛 |
| 二阶 | 40 | 8 | 犟角行家 |
| 三阶 | 90 | 14 | 老牌犟牛 |

达到门槛后自动生效，不消耗升级卷轴，也不自动提高装备的强化等级。成长状态、计数和提示记录写入本局存档。

### 犟角：第三次，才轮到我发言

| 阶段 | 名称 | 未强化基础伤害 | 每第三次有效武器命中 |
| --- | --- | --- | --- |
| 初始 | 犟角 | 2–8 | 无额外追击 |
| 一阶 | 讲理角锤 | 3–10 | 追加 2 点伤害 |
| 二阶 | 抬杠扳手 | 4–12 | 追加 3 点伤害与 1 回合残废 |
| 三阶 | 老班长的犟角 | 5–14 | 追加 4 点伤害、1 回合残废与 2 回合易伤 |

每次武器强化仍增加最低伤害 1、最高伤害 2，原有英雄等级、倔劲与天赋加成继续生效。成长不提升武器阶级，也不替代升级卷轴；附魔随物品保留。第三击计数只来自实际有效命中，不能靠攻击免疫目标空刷。

### 围兜：有黑锅，但不承包所有黑锅

| 阶段 | 名称 | 黑锅上限 | 卸下两层时的额外效果 |
| --- | --- | --- | --- |
| 初始 | 拼斑围兜 | 无 | 无 |
| 一阶 | 值班围兜 | 2 | 无 |
| 二阶 | 不背锅围裙 | 3 | 1 点护盾，2 回合 |
| 三阶 | 老班长的围裙 | 4 | 2 点护盾，2 回合 |

一阶起，穿着围兜受到敌方实际直接伤害时获得一层「黑锅」。下一次有效普通攻击最多卸下两层，每层增加 1 点伤害。高阶的小护盾有 **8 回合冷却**，使用同一种不叠加护盾规则；连续挨打不能无限叠盾。脱下围兜会清空黑锅。

围兜始终保留布甲阶级，成长不把它变成板甲。升级、刻印与换装仍有价值。皇冠升级得到的星牧战铠继承围兜机制，同时保留原护甲的阶级、强化与刻印。

## 四、牛铃的成长与取舍

| 阶段 | 名称 | 新效果 |
| --- | --- | --- |
| 初始 | 不服铃 | 保留顶撞和踏地 |
| 一阶 | 申诉小铃 | 顶撞至少实际移动 1 格且有效伤害目标后，给予其 1 回合虚弱 |
| 二阶 | 调解牛铃 | 解锁 6 回合内的两招交替配合 |
| 三阶 | 主持公道铃 | 解锁「据理力争」 |

### 两招交替

二阶起，实际命中敌人的顶撞或踏地留下 6 回合配合窗口。在窗口内有效命中另一招，可获得以下效果：

| 顺序 | 奖励 |
| --- | --- |
| 顶撞 → 踏地 | 踏地的基础护盾额外 ＋2 |
| 踏地 → 顶撞 | 顶撞伤害额外 ＋2 |

每招仍各耗 3 倔劲与 1 回合。完成配合后窗口消失；连续同招只更新起手，不能触发奖励。空放踏地仍会付费并获得原有基础护盾，但不能获得历练、建立或完成配合。跨楼层或支线不能保留可用配合窗口。既有护盾按原有取较高值的规则处理，不直接相加。

### 据理力争

三阶新增声波行动，消耗 **4 倔劲和 1 回合**。只影响 **2 格内、处于英雄视野、且没有实体墙阻挡**的敌人。基础伤害为 `2＋英雄等级÷4`，扣除防御后的基础计算值至少 1 点，免疫与护盾仍按游戏规则结算；实际造成损失后施加虚弱，普通敌人 3 回合，首领与小头目（`BOSS`／`MINIBOSS`）1 回合。带精英词缀的普通敌人仍按普通敌人处理。

这是短程防守选择：伤害低于顶撞，需要多 1 点倔劲，不提供踏地的基础护盾，不参与两招配合，也不返还倔劲。它不会强制搬动敌人、把首领推进深渊，或用持续硬控锁住敌人。范围内没有有效听众时不会消耗资源或回合。

### 成长手册与牛言牛语

两个入口都是只读操作，不消耗倔劲、回合，也不制造历练。手册显示当前阶段、条件和进化效果；牛言牛语只展示已发现的彩蛋条目。长文本可滚动，物品窗口的标题和按钮固定显示，避免小屏幕中按钮被长说明挤出屏幕。

## 五、转职与英雄护甲技能

击败天狗、使用面具后，沿原版流程二选一：

| 转职 | 玩法 |
| --- | --- |
| 撼地蛮牛 | 顶撞伤害提高 25%，成功冲锋后强化短时间内的下一次有效普通命中；天赋可追加余震、追击或护盾 |
| 守夜牧卫 | 使用牛铃后获得随等级成长的守牧护盾；天赋可保护附近友方，或触发有冷却的少量持续恢复 |

击败矮人王后，用皇冠把护甲转为星牧战铠，并选择一种英雄护甲能力。三项能力各自记录熟练度，在 **3、7 次有效使用后**进入两个熟练阶段；达到门槛后的后续施放获得对应强化。

| 能力 | 基础效果与充能 | 怎样记一次有效使用 | 熟练 3 次 | 熟练 7 次 |
| --- | --- | --- | --- | --- |
| 万蹄奔雷 | 贯穿生物、遇墙停止的直线冲击；英雄留在原处。基础耗 35 充能 | 至少实际伤害一名敌人 | 首个有效命中目标若仍存活，虚弱 2 回合 | 同次至少命中两名敌人，获得 2 点护盾、4 回合 |
| 方寸牧场 | 施法位置建立固定守护区域，墙阻断、换层失效。基础耗 35 充能 | 敌人实际进入有效区域，每次施放最多计一次 | 初始护盾上限 ＋2 | 第三次脉冲起，自己仍在区域内时移除一次残废，每次施放最多一次 |
| 夜半开工 | 临时移动与普通攻击强化、照明、法杖充能及少量倔劲。基础耗 40 充能 | 本次增益期间首次有效普通攻击，每次施放最多计一次 | 施放时移除残废 | 增益持续时间 ＋2 回合 |

熟练度不会降低充能费用；空放、免疫命中或没有敌人经过的牧场不能刷熟练。技能名称和原有天赋保持不变。专属天赋仍为 26 项：一阶 4 项、二阶 5 项、三阶共用 2 项、两种转职各 3 项、三种护甲能力各 3 项；四阶同时保留原有英勇能量。

## 八、本地构建与验证

本轮采用本地编译与测试，当前交付完整 APK 和源码 ZIP。**GitHub 完整 APK 上传与源码分支发布尚未完成**，不提供未发布的下载链接；本轮不运行 GitHub Actions，也不依赖 Actions artifact 自动发布。

环境：JDK 17、Android SDK Platform 36、Build Tools 36.0.0；Gradle 使用仓库自带 wrapper。根目录本地配置 `local.properties`：

```properties
sdk.dir=/你的/Android/SDK
```

构建与检查：

```bash
python3 tools/check_cow_assets.py
bash gradlew --no-daemon :core:test :android:assembleDebug :android:assembleDebugAndroidTest :android:lintDebug
python3 tools/check_apk.py android/build/outputs/apk/debug/android-debug.apk
```

Windows 下使用 `gradlew.bat`。APK 默认输出为 `android/build/outputs/apk/debug/android-debug.apk`；Android 测试 APK 在 `android/build/outputs/apk/androidTest/debug/`。资源检查脚本需要 Pillow。

核心测试覆盖旧功能回归、真实成长事件、资源限制、两招配合、敌友与视线、旧字段迁移和压缩存档往返。Android instrumentation 使用隔离测试槽 99，执行实际 UI 选人、开局、菜单、能力和存档流程。后期等级、装备、部分测试目标与完整相册由测试注入，不代表自然解锁或完整通关。
