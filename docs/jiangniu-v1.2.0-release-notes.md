# v1.2.0 更新日志

## 本次主要改动

- **4个真实的装备形态**：犟角→钢筋抬杠锤→破阵牛角战斧→星陨犟天锤；围兜→值班皮甲→不背锅鳞甲→星牧牛王铠。每阶段改变真正的武器/护甲阶级与物品图标，而非改名。对强化等级、附魔、刻印、第三击计数及皇冠继承做兼容处理。
- **武器特色加强**：成长强化基础伤害与强化曲线；终阶每第三次有效命中追加眩晕、易伤与短盾，但仍受普通攻击规则、命中、力量需求限制。
- **牛铃独立熟练度**：有效施放达到3/8/15次，解锁更远顶撞、每层一次「牛棚盲盒」、高阶外圈踏地与额外控制。
- **随机事件不是装饰**：牛棚盲盒4种后果，含有代价与补偿；同层不可重复开箱。
- **护甲能力终阶**：万蹄奔雷、方寸牧场、夜半开工各自从2档扩为3档，终阶分别强化群战、阵地、续航。
- **18条彩蛋均有机制效果**：消耗品、增益、强化卷轴与收集加倔劲上限；全部一次性，不可刷取。
- **公平性与兼容**：进化不赋予强化卷轴等级，不给空放练级，奖励遵循游戏挑战规则；保留包名 `com.jarvistowne.jiangniu` 和公用测试签名，`versionCode=1200`。

## 如何构建

GitHub Actions 自动流程：[构建记录](https://github.com/Jarvis-Towne/shattered-pixel-dungeon/actions/workflows/build-jiangniu-apk.yml)。工作流成功后发布 `jiangniu-v1.2.0-apk` Release，包含 `Jiangniu-v1.2.0.apk`、SHA-256、签名信息。构建包含核心单元测试与静态检查，Android instrumentation APK 会编译但不等价于跑了安卓模拟器/真机测试。

具体数值、触发条件、各层奖励与实机测试清单参见 [v1.2.0玩法指南](jiangniu-v1.2.0-guide.md)。

原 v1.1.0 分支与可安装 APK 保留，便于对照与回滚。
