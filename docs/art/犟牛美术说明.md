# 犟牛像素美术

## 角色来源与设计

角色身份来自用户提供的 `spritesheet.pre-row4-natural.webp`：黑白拼斑、短角、粗眉、粉色鼻口、圆肚子与短黑蹄。三组原稿均使用内置 imagegen 生成，再通过固定导入脚本裁切、缩小、限制色板和排列到游戏要求的像素网格。

游戏内角色保持 SPD 的 **12×15 像素单帧**。外形刻意简化，保证和原版人物同屏时的比例一致。护甲阶段通过围巾的布色、皮色、铁灰、蓝钢、金色、青绿和紫色区分。眉毛与小角保留为角色识别点。

## 美术提示词摘要

1. **动作图集**：以用户小牛为身份参考，以原版战士图集为像素风格参考；生成七列三行的21个透明动作，粗眉、短角、黑白圆肚、浅青围巾、粉色鼻口；覆盖待机、行走、倒下、顶撞、操作、腾空和读卷轴；严格避免文字、光滑渐变和三维渲染。
2. **物品与技能图标**：六列两行，16×16逻辑像素；第一行是角锤、铜铃、牛乳、围兜、草地护盾、草饼，第二行是牛头、进攻职业、防御职业、冲锋、牧场守护与午夜太阳；透明背景、深色轮廓和有限色板。
3. **选人插画**：十六比九的地牢入口，牛居中偏右，持角锤、戴铜铃和围兜；左侧保持深色安静背景，远处月光与近处琥珀灯光呼应；右下藏有小老鼠与奶瓶。

精确生成提示词、生成文件名与源文件 SHA-256 记录在 `cow-art-sources.json`。生成原稿保留在本次制作工作区；运行时只引用上表中的定稿资源。

## 重新导入

需要 Python、Pillow 和 NumPy，传入本次三张原稿：

```bash
python tools/cow_assets/import_pixel_art.py 精灵原稿.png 图标原稿.png 选人原稿.png
```

脚本中的裁切分界对应本次原稿的实际网格；如果重新生成了排版不同的原稿，应同步调整分界。脚本先复制原版物品图集，只填原本透明的六格，并断言这些位置为空。原版 `items.png` 本身保持原样。

## 检查结果

所有英雄和图标像素的透明度均为0或255；角色图集每个使用中的动画格都有内容；合成物品图集与原图的差异完全位于 `(0,192)—(96,208)`；插画、头像和图标均已渲染检查。游戏内最终布局与可读性仍应结合实际运行截图评估。
