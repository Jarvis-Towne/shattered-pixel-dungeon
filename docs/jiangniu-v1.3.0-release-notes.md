# 犟牛地牢 v1.3.0 更新日志

## 用户反馈与修正重点

- **不再更换任何犟牛专属装备的美术/图标**：修复 v1.2.0 随着阶级改用钝锤、战斧、战锤及皮甲/鳞甲图标的问题，所有形态回到独有 `COW_HORN` / `COW_HIDE`，皇冠战铠维持 `COW_ARMOR`。
- **连续成长 + 阶梯进阶**：实战历练的攻防增量按 `g(p)=round[2(sqrt(1+p/12)-1)]` 持续缓慢增长；12/40/90历练及3/8/14级满足后仍触发三次真正阶级和机制跃迁。
- **不人为封顶成长属性**：删除历练999的限制，Buff保存改为long；技能与牛铃独立使用次数不在12/15处截断，终阶后依旧有平滑的属性增益。
- **开局力量需求10**：专属武器和护甲的进阶不会突然把STRReq从10抬到12；原有升级卷轴还能继续降低力量需求。
- **新物品与随机遭遇**：倔劲苏打、会议休庭卷轴、加班监察员加入牛铃五结果随机事件，并通过两项一次性彩蛋触发奖励；新怪物与物品复用原游戏通用素材、不修改专属美术资源。
- **强化策略保留**：升级、附魔、刻印、原有进阶特殊效果和旧存档兼容，倔劲与主动技能的回合成本依旧有效。

详见 [完整玩法说明](jiangniu-v1.3.0-guide.md)。
