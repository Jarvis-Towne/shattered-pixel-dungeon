# 犟牛地牢 v1.3.0：连续成长、阶段性进阶与牛棚随机事件

> v1.3.0 基于 v1.2.0 开发，保留原版六位英雄。用户要求的核心原则：**专属装备美术资源与图标全程不变**、不因进阶强制更换装备、不让装备被不合理的力量需求反噬。

## 一、两条不同的成长曲线

- **连续成长（smooth progression）**：只需要真实战斗积累历练，基础武器伤害与专属护甲防御在每个进阶阶段内部逐步提升，最后一个进阶阶段之后也不停止。原先的 999 历练封顶已删除，主历练使用 `long` 存档。
- **阶梯进阶（discrete evolution）**：第 12/40/90 点历练分别达到英雄 3/8/14 级后，实际装备 `tier` 提高并额外解锁新的攻击、控制和防御机制。升阶绝不清零历练，不重置道具，也不强加进阶所对应的标准沉重装备需求。
- **实战才能获得成长**：有效普通攻击、真实敌方直接伤害、有效牛铃施放、有效护甲能力各计一次。查看菜单、等待、无效或免疫目标、未真正命中的技能不算。
- **战斗资源仍有限**：倔劲是主动技能消耗资源，仍有上限；无硬上限指的是永久累积历练、技能熟练次数，以及它们贡献的基础属性项，不代表可无限施法或无条件获得额外物品。

基础成长函数为

```text
p = 本局积累的有效历练（≥ 0）
g(p) = round[ 2 × ( sqrt(1 + p / 12) - 1 ) ]

专属武器未考虑附魔/天赋时：
min(L, p, t) = t + 1 + L + g(p)
max(L, p, t) = 4(t + 1) + (t + 1)L + 2g(p)
其中 t = 阶梯进阶得到的实际装备阶级（1～4），L 为武器强化等级。
护甲 DRMax 在原阶级防御公式上另加 g(p)，DRMin 的下界有较小平滑提高。
```

这个函数本身连续、单调且边际增幅递减，实际面板是整数，会出现自然的取整台阶，但**不会像 v1.2.0 那样只有三个阶段突变**。没有 999 次历练封顶；实际的升级卷轴及装备自身 `+N` 强化也继续有效。这里的属性数值随游戏的数值整数表示范围受到技术限制，而不是人为设定玩法封顶。

## 二、原始美术恒定，四个名称只是同一件装备的阶段名

| 历练与等级门槛 | 同一把犟角的阶段名称 | 同一件拼斑围兜的阶段名称 | 实际 tier |
| --- | --- | --- | --- |
| 开局 | 犟角 | 拼斑围兜 | 1 |
| 12 历练且 3 级 | 钢筋抬杠锤 | 值班皮甲 | 2 |
| 40 历练且 8 级 | 破阵牛角战斧 | 不背锅鳞甲 | 3 |
| 90 历练且 14 级 | 星陨犟天锤 | 星牧牛王铠 | 4 |

本版**彻底撤销 v1.2.0 的物品图标更换**。所有阶段的专属武器都保持 `ItemSpriteSheet.COW_HORN`，所有阶段的原始围兜都保持 `ItemSpriteSheet.COW_HIDE`，皇冠战铠保持 `COW_ARMOR`。原有 PNG 和资源表不需要修改，已有强化、附魔、刻印、第三击节奏与旧存档不因为换阶级而被抹掉。

### 力量需求特别修复

原版普通装备力量需求与 tier 挂钩：不强化时基准为 `8 + 2×tier`。v1.2.0 直接提高 tier 会让二阶专属装备需求突然变成12，角色却可能仍只有10力量。v1.3.0 的专属装备保持 **初始力量需求10**，随着进阶同步抵消额外的 `2×stage` 要求。升级卷轴按原版规律仍可以逐步降低需求。皇冠升级如果继承了更重、等级更高的其他护甲，则会按其原本档次和专属进阶补偿计算。

### 进阶特殊机制

武器在实战累积第三次有效命中时，阶段一追加伤害、阶段二进一步提供残废，阶段三再加入易伤、短时眩晕与2点守牧盾。护甲随着阶段解锁积攒、卸下黑锅、短盾冷却及较重攻击的少量额外减免。两者各自保留 v1.2.0 的玩法构筑，没有利用历练免费生成强化卷轴。

## 三、本命牛铃与三项英雄技能也持续长大

- **牛铃（独立熟练度）**：第3/8/15次有效施放分别获得顶撞扩程、每层一次随机事件、终阶外圈踏地和控制；第16次之后仍持续增长牛铃伤害。独立平滑增量约为 `round[1.3×(sqrt(1 + 有效施放/5)-1)]`。
- **万蹄奔雷、方寸牧场、夜半开工**：第3/7/12次有效实战激活阶级机制；第13次之后仍保存并继续增加计数。附加平滑增长 `round[sqrt(1+使用次数/4)-1]`，分别帮助提升冲击伤害、护盾/部分持续时间、夜班持续时间及一定攻击加成。战斗资源与护甲能量消耗规则未取消。

## 四、牛棚盲盒：更实在的风险收益

共同历练二阶、牛铃熟练二阶且至少4倔劲时，牛铃菜单解锁盲盒。消耗4倔劲和1回合，同一主地牢深度**只触发一次**（已抽层记录持久化，返回旧层不可刷）。五种等概率结果：

1. **倔劲苏打（新增药水）**：祝福5回合、守牧护盾，犟牛再恢复少量倔劲。
2. **会议休庭卷轴（新增卷轴）**：3格内无墙遮挡可见敌人短暂虚弱/残废，自己获得守牧护盾与充能。
3. **工伤保险**：5点临时护盾、返还1倔劲。
4. **突击检查**：虚弱3回合，但得到一瓶治疗药水。
5. **加班监察员（新增特殊怪）**：在附近合法空地出现，有近战压制技能，击败后必定尝试掉落药水或卷轴；若地形过于狭窄无法生成，则自动转换为苏打补偿。

新怪物复用原版豺狼人动画，不进入原版普通刷怪表；两个新增消耗品复用**通用**药水/卷轴图标。怪物召唤有可通行/不在深渊/不重叠/可见且无遮挡的空间判据。

## 六、兼容、测试和可回滚

- GitHub 保持 `jiangniu-v1.2.0` 不变；开发在 `jiangniu-v1.3.0` 分支。
- 包名 `com.jarvistowne.jiangniu`、原公开体验版签名不变；Android `versionCode=1300`。
- `CowLegend` 原本的 int 历练从 `Bundle.getLong` 迁移，老存档无需人为修改；v1.2.0 专属道具图标即使写过新图标，也在重装备/进阶或恢复时回归原美术。
- CI 自动进行无窗口核心逻辑测试、专属资源校验、Android APK 与 AndroidTest APK 编译、Lint、APK 完整性、zipalign 及签名校验。编译 AndroidTest APK **不等于在模拟器/真机上跑过 instrumentation**，因此保留实机回归要求。

建议重点手动复查旧存档覆盖安装、力量不足惩罚修复、最终阶段后持续成长、召唤怪物的AI与掉落、满背包奖励、连续开楼层盲盒的防刷约束，以及挑战模式下的药水/卷轴行为。
